# Operator reference

Generated by `atidarla docs` from the operator registry. Do not edit by hand.

## IMG (39)

- [Analyze](img/analyze.md) — Measures the whole image on the GPU: average r, g, b, a and luminance, and the darkest and brightest luminance, as channels (a frame or two behind the image).
- [Blend](img/blend.md) — Crossfades from input A to input B.
- [Bloom](img/bloom.md) — Adds a glow around bright areas.
- [Blur](img/blur.md) — Gaussian blur.
- [Cache](img/cache.md) — Delays the input by a number of frames (frame history).
- [Channel Image](img/channel_image.md) — Draws SIG channels as an image: waveforms (samples along x, a row per channel) or band rows (channels along x). Feeds ISF audio inputs.
- [Channel Mix](img/channel_mix.md) — Rebuilds each output channel as a weighted sum of the input's R, G, B and A.
- [Chroma Key](img/chroma_key.md) — Makes pixels close to a key colour transparent.
- [Composite](img/composite.md) — Combines input A with input B using a blend operation.
- [Constant](img/constant.md) — Fills the image with one colour.
- [Crop](img/crop.md) — Keeps a rectangle of the input. By default the output is that rectangle at its own pixel size; `input` size stretches it to the input's size instead.
- [Displace](img/displace.md) — Offsets input A by input B: red moves horizontally, green vertically, around mid-grey.
- [Edge](img/edge.md) — Outlines: the strength of luminance edges (Sobel).
- [Feedback](img/feedback.md) — Outputs the previous frame of the `loop` input, closing a feedback loop; outputs `in` until the loop has a frame or while reset is on.
- [Fluid 2D](img/fluid.md) — An incompressible 2D fluid carrying coloured dye. A built-in emitter and the `dye` and `velocity` images stir it; Reset clears it.
- [HSV Adjust](img/hsv_adjust.md) — Rotates hue and scales saturation and value.
- [Kaleidoscope](img/kaleidoscope.md) — Folds the input into mirrored segments around the centre.
- [Level](img/level.md) — Brightness, contrast, gamma, opacity and invert.
- [Lookup](img/lookup.md) — Recolours input A through a lookup image B: each pixel's luminance picks a colour along B's horizontal centre line.
- [Luma Key](img/luma_key.md) — Makes pixels outside a luminance range transparent.
- [Mirror](img/mirror.md) — Reflects one half of the image onto the other.
- [Movie In](img/movie_in.md) — Plays a movie or still image. HAP, HAP Alpha, HAP Q and HAP R are decoded natively and upload as GPU-compressed textures; PNG and JPEG stills load as one frame; other codecs (H.264, HEVC, ProRes, VP9 and more) decode through FFmpeg, with hardware decoding where the platform has it, in builds with FFmpeg.
- [Noise](img/noise.md) — Fractal gradient noise. Animate `z` to move through it over time.
- [Normal Map](img/normal_map.md) — Treats luminance as height and outputs tangent-space normals (RGB = XYZ × 0.5 + 0.5).
- [Projection](img/projection.md) — Converts between panoramic and camera projections: equirectangular (360°), fisheye, perspective and a cubemap cross, with a yaw/pitch/roll rotation.
- [Ramp](img/ramp.md) — A gradient between two colours: horizontal, vertical, radial or angular.
- [Reaction-Diffusion](img/reaction_diffusion.md) — A Gray-Scott reaction-diffusion simulation growing organic patterns from a seed; bright areas of the `seed` input add more.
- [Remap](img/remap.md) — Samples input A at the coordinates stored in input B's red and green channels.
- [Resolution](img/resolution.md) — Resamples the input to another size: a fraction of the input (or of the project size when nothing is connected), or exact pixels. Operators after it work at the new size.
- [Ripple](img/ripple.md) — A water-surface simulation: bright areas of the `drive` input push the surface, and waves spread and fade.
- [Shape](img/shape.md) — A circle, rectangle or regular polygon with soft edges.
- [Slope](img/slope.md) — The luminance gradient: red = horizontal slope, green = vertical slope, around mid-grey.
- [Switch](img/switch.md) — Outputs one of up to four inputs, optionally blending between neighbours.
- [Text](img/text.md) — Draws text (several lines allowed) over the input or a background colour, in a built-in or TrueType/OpenType font.
- [Threshold](img/threshold.md) — White where a channel is above the threshold, black elsewhere.
- [Tile](img/tile.md) — Repeats the input in a grid.
- [Time Machine](img/time_machine.md) — Shows each pixel of `in` from a different moment: the luminance of `time` (black = now, white = oldest) picks how many frames back, blending between frames. Without `time`, the whole image is delayed by Offset.
- [Transform](img/transform.md) — Translates, rotates and scales the input around a pivot.
- [WGSL](img/wgsl.md) — A full-screen shader you write in WGSL: the body of `fn shade(uv: vec2f) -> vec4f` (uv from the top-left). Inputs are `in0` and `in1` with sampler `samp`; `p1()`…`p4()` return the four parameters, and `time()`, `resolution()` and `frame()` are available. A file reloads whenever it is saved; the last working shader keeps running while you edit.

## SIG (29)

- [Audio File In](sig/audio_file_in.md) — Plays a WAV file as audio-rate channels (`left`/`right`, or `mono`). Decoding runs off the render thread.
- [Audio In](sig/audio_in.md) — Live audio from an input device as audio-rate channels (`left`/`right`, `mono`, or `chan1`…). The device opens and runs on its own thread.
- [Audio Out](sig/audio_out.md) — Plays audio-rate channels (from Audio In, Audio File In or audio processing) on an output device; mono feeds every speaker, otherwise channels map in order. Converts to the device rate; passes the input through.
- [Beat](sig/beat.md) — A tempo clock: `beat` count, `beat_phase` 0–1 within the beat, `bar` count and `bar_phase`.
- [Constant](sig/constant.md) — Up to four named channels with constant values.
- [Count](sig/count.md) — Counts how many times the input rises above a threshold. Outputs `count`.
- [DMX Out](sig/dmx_out.md) — Sends input channels (0–1) as DMX512 slots from Start, over Art-Net or sACN (E1.31). The universe is sent when it changes (at most 44 times a second) and repeated every second.
- [Envelope](sig/envelope.md) — Follows the loudness of an audio input per channel (RMS or peak) with attack and release.
- [Filter](sig/filter.md) — One-pole low-pass (smooth) or high-pass (changes only) filter per channel.
- [Input Devices](sig/input.md) — Mouse, keyboard or gamepad as channels. Mouse: position over the viewed image (0–1, y up), buttons and wheel. Keyboard: 1 while each listed key is held. Gamepad: sticks, triggers and buttons.
- [Lag](sig/lag.md) — Smooths changes with separate rise and fall times.
- [LFO](sig/lfo.md) — A low-frequency oscillator: sine, triangle, square or ramp over time. Outputs channel `lfo`.
- [Limit](sig/limit.md) — Clamps channels to a range, optionally quantising to a step.
- [Math](sig/math.md) — Combines A with B channel by channel, then maps the range from→to.
- [Merge](sig/merge.md) — Combines the channels of up to four inputs, in input order.
- [MIDI In](sig/midi_in.md) — Channels from a MIDI input: controllers (`ch1_cc7`), notes (velocity while held, 0 after release), pitch bend, pressure and program, added as they arrive. The port runs on its own thread.
- [MIDI Out](sig/midi_out.md) — Sends each input channel (0–1) as a MIDI control change, numbered from First CC, whenever its value changes; passes the input through.
- [Noise](sig/noise.md) — Smooth random channels that wander over time.
- [Onset](sig/onset.md) — Detects onsets (beats, hits) in an audio input by spectral flux. Outputs `onset` (1 on detection frames) and `flux`.
- [OSC In](sig/osc_in.md) — Receives OSC on a UDP port; each numeric address becomes a channel (`/a/b` → `a_b`) holding its latest value.
- [OSC Out](sig/osc_out.md) — Sends each input channel as an OSC float message `<prefix>/<channel>` whenever the input changes, and passes it through.
- [Pattern](sig/pattern.md) — One channel of Length samples shaped by a waveform over Cycles; Speed scrolls it over time. Feed Channel Image to turn it into a texture, or index it from other operators.
- [Select](sig/select.md) — Keeps only the named channels.
- [Spectrum](sig/spectrum.md) — Band energies of an audio input (log-spaced `band1`…`bandN`, a full-scale sine reads about 1) plus its RMS `level`.
- [Speed](sig/speed.md) — Integrates each channel over time: the input is a rate per second.
- [Timecode In](sig/timecode_in.md) — SMPTE timecode from MIDI Time Code or from LTC audio. `time` is the position in seconds and keeps moving between updates; `locked` is 1 while code is arriving. The input runs on its own thread.
- [Timer](sig/timer.md) — Counts seconds while playing: `seconds`, `fraction` of the length and completed `cycles`.
- [Trail](sig/trail.md) — Keeps the recent history of each channel: each output channel holds the last N frames, oldest first.
- [Trigger](sig/trigger.md) — An attack/decay envelope fired when the input rises above a threshold or Fire is switched on. Outputs `trigger`.

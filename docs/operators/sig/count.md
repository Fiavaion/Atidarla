# Count (`sig.count`)

SIG · version 1 · cook budget 20 µs

Counts how many times the input rises above a threshold. Outputs `count`.

## Inputs

| Name | Type | Notes |
|---|---|---|
| `in` | Sig | optional |

## Outputs

| Name | Type | Notes |
|---|---|---|
| `out` | Sig |  |

## Parameters

| Name | Label | Type | Default | Range / options | Description |
|---|---|---|---|---|---|
| `threshold` | Threshold | float | `0.5` |  | Input value that counts as high. |
| `reset` | Reset | toggle | `false` |  | While on, holds the count at zero. |

## Platforms

All platforms.

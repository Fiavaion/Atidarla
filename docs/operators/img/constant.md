# Constant (`img.constant`)

IMG · version 1 · cook budget 50 µs

Fills the image with one colour.

## Inputs

None.

## Outputs

| Name | Type | Notes |
|---|---|---|
| `out` | Img |  |

## Parameters

| Name | Label | Type | Default | Range / options | Description |
|---|---|---|---|---|---|
| `colour` | Colour | colour | `[0.0,0.0,0.0,1.0]` |  | Fill colour (RGBA). |

# Displace (`img.displace`)

IMG · version 1 · cook budget 80 µs

Offsets input A by input B: red moves horizontally, green vertically, around mid-grey.

## Inputs

| Name | Type | Notes |
|---|---|---|
| `in` | Img | optional |
| `by` | Img | optional |

## Outputs

| Name | Type | Notes |
|---|---|---|
| `out` | Img |  |

## Parameters

| Name | Label | Type | Default | Range / options | Description |
|---|---|---|---|---|---|
| `amount` | Amount | float | `0.05` |  | Displacement as a fraction of the image at full deviation. |

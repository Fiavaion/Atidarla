## Architecture (decision A54)

**One graph.** The Stage and the Timeline own no media pipeline and no second data model. They are views and controllers over the network the Patch edits:

| Concept | In the graph | Notes |
|---|---|---|
| Clip | Any IMG node wired into a layer slot (a Movie In, a generator chain, a Pack instance, a Share In) | Clip settings (label, launch mode, beat length) live on the layer as per-slot parameters (`slots` list), so a clip needs no wrapper node |
| Layer | `img.layer`: IMG inputs `clip0`…`clip15`, params `target` (slot to play, −1 = none), `transition` (cut, fade, wipe) and its length in beats or seconds, `quantise` (off, beat, bar), `opacity`, `blend`, `bypass`; optional SIG input `clock` | Internal state: the slot playing, the transition in progress. Switches at the next quantum boundary read from `clock`. Status line shows the playing slot |
| Column | Slot index across layers | Column launch = set `target` on every layer of the deck in one edit |
| Deck / composition | `img.mixer`: IMG inputs `layer0`…`layer15`, params per input (opacity, blend, A/B/none crossfader group), `crossfader`, `master` | A project may have several decks; the Stage shows the one marked `stage = true` |
| Effects | Ordinary IMG nodes or Packs between a clip and its slot, a layer and the mixer, or after the mixer | The Stage shows them as chains; adding one is a graph edit |
| Clock | `sig.beat` grows tap, nudge, resync, MIDI clock in/out and audio follow (from `sig.onset`/`sig.spectrum`); channels `beat`, `beat_phase`, `bar`, `bar_phase`, `bpm`, plus a `downbeat` pulse | Ableton Link waits for A14 (Proposed) |
| Launch | A parameter edit (`target`), so it is undoable, saved, recordable as a cue, and deterministic offline | Launch modes are app behaviour over `target`: trigger, toggle (again = stop), flash (held), one-shot (back after the clip's length) |
| Live control | MIDI/OSC mappings and timeline tracks write **live values** (`Engine::set_live`): above binding, expression and stored value; not edits, not saved, never undone | `atd-gpu` `LiveValues`, built 2026-10-30 |
| Timeline | `timeline.toml` in the project: tracks of keyframes per (node, parameter), curves, markers, cues | Evaluated by `atd-timeline` at the playhead into live values and launch edits |
| Mappings | `mappings.toml`: source (MIDI note/CC/channel, OSC address) → target (node, parameter), range, curve, toggle/momentary, pick-up | Learn: arm a parameter, move a control |
| Outputs | `cmp.window` nodes (PRD §6 CMP "Window"), each with slices: source rect → destination quad, mask, grid/bezier warp, edge blend; test patterns | Windows open on the app's displays; headless renders ignore them |
| Show export | `atidarla export-show <project> <out>`: a folder (and zip) with every referenced file copied under `media/` and paths rewritten relative; Packs are already in the project | Import = open the folder; platform-flagged nodes report their substitute (A19) |

Rules this keeps: rule 1 (MIDI/OSC/DMX I/O stay on their threads; the layer switches inside its cook), rule 2 (layers and mixer use the texture pool), rule 8 (`timeline.toml`, `mappings.toml` are text with stable IDs and round-trip tests in `atd-format`), rule 6 (nothing platform-specific except outputs on real displays).

## Where the crates stand

`atd-kernel`, `atd-ops-pnt`, `atd-ops-msh`, `atd-ops-mat` and `atd-ops-cmp` are empty stubs. Already done in M1 and **not** M2 work: the 2D solvers Reaction-Diffusion, Fluid 2D and Ripple, expressions (A22) and the Python worker. NCA (the fourth 2D solver) is still to do. **FR-K5 is only partly done**: `img.wgsl` is a full-screen fragment shader (`in0`/`in1`, `p1()`-`p4()`); the `#bind` declarations, tile size and iterations of FR-K5, and any geometry or compute form of it, are M2 work (corrected 2026-10-18; an earlier version of this draft listed FR-K5 as done).

## Proposed order (what can start before any ratification)

1. FR-H1 deterministic render (AC4): self-contained, benefits every later milestone, and gives a way to test the rest.
2. Attribute-buffer framework and the PNT operators that need no kernel (AC1, part of AC5).
3. MSH operators, once the licence spike names allowed libraries.
4. Packs (FR-P4) and Python custom ops.
5. Kernel DSL (AC2, AC3) only after **A12** is ratified.

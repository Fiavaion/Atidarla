## Architecture

```
render thread (cook)                      atd-ai worker threads                 host process
ai.* node ──copy input→ readback buf ──▶ Link: mailbox (preallocated) ──▶ frame.submit ──▶ adapter
   ▲  governor blend/hold                    supervisor: spawn, health 1 s,       (shm ring or
   └──upload◀── latest result (mailbox) ◀──  restart, route, egress gate   ◀──   inline payload)
```

- **Render thread** only copies the input into a readback buffer (recorded in the cook's
  encoder, mapped in `after_submit`), hands finished pixels to the node's link without
  waiting, uploads a newer result when one is there, and draws the governor's output.
  Buffers are preallocated per size; nothing allocates per frame after warm-up (rule 2).
- **`atd_ai::link`**: one per AI node. A mailbox (latest input, latest result) shared
  with a worker that owns the host session. At most N frames in flight (default 2).
- **`atd_ai::supervisor`**: hosts by name (`local`, `lan:<name>`, `cloud:<provider>`),
  health every second, restart of local hosts, state for the UI (Starting, Ready,
  Restarting, Failed + reason).
- **`atd_ai::router`**: per-node policy list (`local → lan:studio → cloud:decart`),
  capability matching (adapter, vendor, `win+nvidia` real-time flag), fallback on
  failure or latency budget, spend meter and cap, Sovereign gate.
- **`atd_ai::egress`**: the only way atd-ai opens a socket. Classifies the address
  (loopback, private, link-local, CGNAT, ULA, `.local` → LAN; anything else → internet)
  and refuses internet addresses in Sovereign mode.
- **Output Governor** (FR-A6): policy per node: `hold`, `blend` (cross-fade between the
  last two results over the measured AI interval), `flow` (blend along a coarse
  block-matching flow field), `passthrough` (input with an effect until the first result).
  Shows effective AI fps.
- **Model manager** (FR-A12, A61): catalogue with licence class (commercial-safe /
  restricted / non-commercial), download after explicit acceptance, SHA-256, per-project
  manifest, "commercial-safe only" project filter.

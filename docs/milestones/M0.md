## What exists after this pass

- **Workspace:** every crate in PRD §5.2 exists (`crates/lsr-*`). Crates scheduled for later milestones are documented stubs that name their milestone. The `lsr-ops-*` crates expose `register(&mut Registry)` and register nothing yet, because rule 7 says every operator must ship complete.
- **`lsr-core`:** platform detection, capability flags and the operator registry, with deterministic JSON and JSON-Schema export (`lasair registry`).
- **`lsr-gpu`:** headless device bring-up, adapter report and vendor detection.
- **`lsr-app`:** the eframe/wgpu shell with an in-house dock (`dock.rs`, see A20), the node canvas (`canvas.rs`: pan, zoom about the cursor, grid) and Platform/Operators panels.
- **`lsr-cli`:** the `lasair` binary. `bench` writes `lasair-bench/1` JSON (FR-H4). `registry` prints all schemas. `render`, `run`, `bake` and `serve` exit with code 2 and name the milestone they belong to.
- **`lsr-py`:** the embedded `lasair` module skeleton. Its test boots CPython 3.13 and imports the module, which proves PyO3 builds and links in CI.
- **`lsr-ai` + `ai-host/`:** the spike (d) protocol prototype, with integration tests that run against a real Python host process.

## Decisions for Mark

1. **Ratify or amend A5, A8, A9, A11–A14** (PRD §0). Nothing built so far depends on them beyond M0 scaffolding.
2. **A20 (new, Proposed): in-house dock widget.** `egui_dock` 0.21 and `egui_tiles` 0.17 both target egui 0.36. egui 0.37 shipped on 2026-10-15, and dropping to 0.36 would also break the wgpu 30 pin. So `lsr-app` has its own small dock module that mirrors `egui_dock`'s API. The proposal is to switch back to `egui_dock` once it supports egui 0.37. Recorded in the PRD decision log.
3. **Geogram:** accept it with `GEOGRAM_WITH_HLBFGS/TETGEN/TRIANGLE=OFF` and an in-house `-sys` crate, or prefer the MIT alternatives (meshoptimizer 1.3 `meshopt_remesh`, pure-Rust options). See `docs/spikes/msh-licences.md`.
4. **Copyright holder** for the licence files: currently "The Lasair Contributors" until the company/org name is settled (PRD §12 Q5).
5. **Hardware access** for spikes a, b, c and e: an RTX 4070 Windows PC, an Apple-Silicon Mac, and an Apple Developer ID for notarisation.

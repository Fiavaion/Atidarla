# Tír (working title)

Planning documents for an open-source, node-based heightmap/terrain generator: Apple Silicon first, CUDA-ready, with a live Unreal Engine 5.8 Landscape bridge and a learn-first UX for students new to node-based workflows.

- `RESEARCH.md` — market, algorithms, UE 5.8 integration, Apple Silicon / cross-platform compute, learning design.
- `PRD.md` — decisions (all Proposed), requirements, node library, performance targets, milestones M0–M6.

This is a separate product from Atidarla. It lives here until its own repository is created (PRD §12 Q3).
